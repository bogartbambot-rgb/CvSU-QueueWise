QueueWise Privacy Notice

QueueWise is an academic demonstration. Registration collects your name, student number, email address and a password hash. The request system stores your selected documents, date needed, reason, and status history so authorized registrar staff can review simulated requests.

Your Student or Alumni account can access its own requests, while registrar staff can review and process submitted requests. Email addresses are used for verification. Do not enter real sensitive documents or personal information beyond what is needed for testing.

Database records are stored on the configured server. This prototype does not guarantee real university processing or a formal retention period.

PROGRESSIVE WEB APP

Install QueueWise

Use QueueWise in its own app window with an icon on your desktop or home screen.

01
Android — Chrome

Open the QueueWise HTTPS website directly in Chrome. Tap the browser's ⋮ menu → Install app, or Add to Home screen when available. Confirm the installation.

02
iPhone — Safari

Open QueueWise in Safari, tap Share → Add to Home Screen → Add. If offered, enable Open as Web App. iOS does not show the same automatic install popup as Android.

03
If you cannot find Install

Open the link in your regular browser rather than inside Facebook, Messenger, or an in-app browser. On desktop Chrome/Edge, use the address-bar install icon or browser menu. After installing, launch QueueWise from the home screen.

If QueueWise is already installed, you might not see Install again. Installation availability depends on your device and browser; live requests still require an internet connection and a running server.
